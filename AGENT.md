# Project: Pearloria Registration Landing Page

## Goal
Single-purpose sales landing page focused only on business registration
(Business Name, LTD, BN→LTD upgrade). Not a full homepage — drop NGO,
trademark, TIN, and annual returns content entirely.

## Audience
Nigerian entrepreneurs actively looking to register a business.

## Primary CTA (only CTA — no competing actions)
"Get Registered Now" button → pre-filled WhatsApp link:
https://wa.me/2347072613455?text=Hi%2C%20I%20want%20to%20register%20my%20business
Repeat this exact CTA at: hero, mid-page, closing section.

## Visual direction
- Primary color: deep navy (~#0F1E3D)
- Accent/CTA color: warm gold/amber (~#D4A017)
- Font: Geist (Nova default — already configured)
- Feel: clean, confident, minimal, generous whitespace, checklist-like precision

## Tech stack
Next.js, Tailwind CSS v4, shadcn/ui (Base UI, Nova preset) — already scaffolded.

## Section order
1. Hero (kicker + headline + subheadline + CTA + micro-line)
2. Trust bar (CAC Compliant, Trusted by Startups & NGOs, No Hidden Charges, Ongoing Support)
3. What We Register (3 cards: Business Name, LTD, BN→LTD upgrade)
4. Why Choose Pearloria (3 items: Expert Guidance, Full CAC Compliance, Transparent Pricing)
5. How It Works (3 steps: Consultation → We Handle It → Receive Certificate)
6. Testimonials (Sarah O., Emeka A. — real quotes, don't alter)
7. Closing CTA
8. Footer (minimal: logo, tagline, WhatsApp, link to main site)

## Working process
Before writing code for any new section: describe your planned component
structure and approach, and wait for confirmation before implementing.
Build and check one section at a time in the browser — don't generate
multiple sections in one pass.
